Method & scope

A narrow tool,
by design.

Light reverses the known alpha blend for supported visible Gemini marks. It tests calibrated placements, measures confidence, and stops instead of guessing when the signal is weak.

See supported profiles →
  1. 01 / Decode

    The browser reads your image into a local canvas.

  2. 02 / Match

    Embedded maps score known sizes and bottom-right placements.

  3. 03 / Reverse

    The matched alpha blend is reversed and a fresh image is encoded.

Scope note

This handles the visible image mark only. It does not remove SynthID or other invisible provenance signals.
