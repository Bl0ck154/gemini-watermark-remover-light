How it works

Detect. Remove. Rebuild.

Video Light samples multiple frames, searches the bottom-right area for a supported Gemini/Veo mark, then processes the clip frame by frame. The MP4 is rebuilt locally in the browser.

  1. 1
    Detect

    Known layouts are checked first. If they are weak, a bottom-right smart search looks for relocated and smaller diamond marks.

  2. 2
    Remove

    Reverse alpha blending is applied only when frame evidence is strong enough. Soft cleanup is optional.

  3. 3
    Rebuild

    Mediabunny and WebCodecs preserve the source frame timing while the video is re-encoded as H.264 MP4.

Current scope

Light first.
Fail closed.

Video Light currently targets visible Gemini/Veo diamond-style marks. If detection is weak or ambiguous, it stops instead of modifying a random part of the video. Heavy compression can still leave a faint residual; a stronger local ML cleanup mode can be added later.
